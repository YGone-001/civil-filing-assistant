## 4. 议程

### 环节 1：范围、边界与记录规则

- 确认产品范围：仅出租人追索欠租，还是也支持承租人。
- 确认官方要素式表格是否采用；不把“官方存在”直接等同于“必须采用”。
- 确认事实完整性边界：不得从缺失或未确认的输入生成事实断言。
- 确认审阅记录要求：审阅人、资格、日期、逐项决定、理由、依据和待补材料。
- 确认“无法判断”是合法结论，不等于通过。

### 环节 2：P0 问题（必须先决）

| ID | 问题 | 当前行为摘要 | 需要审阅人决定 |
|---|---|---|---|
| LRQ-01 | 产品是否只做出租人追索欠租？ | 模型按出租人设计，无原告角色字段 | 维持出租人范围／扩展承租人／双模板 |
| LRQ-02 | 已解除合同是否需要确认解除请求？ | 只在“请求解除”时提出解除请求；已解除只在事实中写日期 | 是否需要确认之诉 |
| LRQ-03 | 返还房屋与损失赔偿是否拆分？ | 只请求腾退返还，不主张解除损失 | 是否拆分、是否支持损失赔偿 |
| LRQ-04 | 采用官方要素表还是叙述式？ | 当前为叙述式起诉状 | 采用官方版式／保留叙述式并补要素 |
| LRQ-05 | 事实叙述是否有未经用户确认的断言？ | 填写催缴情况时追加“至今未支付”，部分付款样本也复现了该句。返还“未确认”时省略返还请求 | 是否需要补充确认字段或改写表述 |
| LRQ-06 | 是否必须写明请求依据？ | 当前不引用合同条款或法律条文 | 必须／可选／由用户填写 |

P0 未形成决定前，不进入实施范围讨论。

### 环节 3：P1 问题（请求与程序）

| ID | 问题 | 需要审阅人决定 |
|---|---|---|
| LRQ-07 | 迟延租金利息／违约金如何主张 | 固定金额是否足够；是否支持计算基数、标准、截止日和至清偿日 |
| LRQ-08 | 是否主张房屋占有使用费 | 是否纳入及条件 |
| LRQ-09 | 是否主张水电费等费用 | 是否纳入及如何区分 |
| LRQ-10 | 是否主张返还押金 | 承租人场景或抵扣场景 |
| LRQ-11 | 是否支持实现债权的费用 | 是否结构化及凭证提示 |
| LRQ-12 | 是否要求标的总额 | 用户填写或系统汇总；如何避免静默计算 |
| LRQ-13 | 诉讼费用是否始终主张 | 默认主张或用户选择 |
| LRQ-14 | 是否采集仲裁／法院管辖约定 | 是否增加栏目及与专属管辖衔接 |
| LRQ-15 | 是否采集诉前保全 | 是否增加保全法院、时间、案号 |

### 环节 4：P2 问题（当事人、证据与程序意愿）

| ID | 问题 | 需要审阅人决定 |
|---|---|---|
| LRQ-16 | 证据清单是独立文书还是起诉状栏目 | 独立／并入／两者都保留 |
| LRQ-17 | 送达地址确认书没有官方对应模板，是否继续使用 | 保留项目自拟／取消／替换 |
| LRQ-18 | 当事人信息和第三人是否足够 | 必补字段；是否支持第三人 |
| LRQ-19 | 委托代理人授权是否足够 | 是否增加一般／特别授权 |
| LRQ-20 | 是否采集调解意愿 | 纳入／不纳入／仅提示 |
| LRQ-21 | 标题案由副标题和签署栏格式是否调整 | 调整／保留 |

### 环节 5：结论记录与后续

- 审阅人填写审阅包第 7 节的审阅记录。
- 逐项填写决定、理由、依据、待补材料和日期。
- 给出总体结论：通过／有条件通过／不通过／无法判断。
- 明确哪些问题因材料不足无法判断，不得默认通过。
- 将结果写入工作包和映射登记；未批准项保持未批准。
- 权利与再分发审查、工程授权和发布批准仍分别进行。
