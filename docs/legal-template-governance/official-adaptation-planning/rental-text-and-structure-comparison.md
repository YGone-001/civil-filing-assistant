## 1. 比较对象与方法

### 1.1 官方文本

本次比较只针对 `spc-2025-notice-pdf` 中“民事起诉状（房屋租赁合同纠纷）”的空白表和填写实例。该官方文本是要素式表格，包含当事人信息、诉讼请求、约定管辖和诉前保全、事实与理由、对纠纷解决方式的意愿以及签署栏。

### 1.2 当前输出

当前程序使用 `RentalCaseModel` 和 `DocumentGenerator` 生成叙述式民事起诉状，并另行生成证据清单和送达地址确认书。比较时使用一份完全虚构的样例，包含：

- 原告为自然人，被告为有限责任公司；
- 原告委托律师代理；
- 合同状态为“请求解除”，房屋“未腾退”；
- 欠租金额 9000 元，违约金 500 元；
- 已填写催缴情况。

样例不包含任何真实姓名、证件号码、地址、电话或案件事实。

### 1.3 方法

逐节对照官方空白表的栏目、填写实例的填写方式和当前生成文书的段落、表格及字段来源；同时核对 `models/case_model.py` 中的 `RentalCaseModel`、`views/pages/rental.py`、`utils/doc_generator.py` 和 `utils/evidence_library.py`。

### 1.4 限制

- 只比较该 PDF 的房屋租赁合同纠纷部分，不代表其他法院、地区或版本。
- 不判断官方表格是否对本案具有强制适用性，也不判断当前文书是否满足任何法院的立案要求。
- 不进行法律适用性、证据充分性或权利归属的实体判断。
- 未对官方文本进行复制、改写或再分发。

## 2. 总体结论

| 维度 | 结论 |
|---|---|
| 文书风格 | 官方是要素式表格；当前是叙述式起诉状。两者不是同一版式。 |
| 原告角色 | 官方按出租人／承租人的不同请求分流；当前模型明显偏向出租人（房东）追索欠租。 |
| 核心欠租请求 | 当前覆盖欠付租金金额和欠租期间，是本比较中覆盖度最高的部分。 |
| 其他请求 | 官方表中的交付房屋、占有使用费、水电费、押金、实现债权费用、标的总额等没有对应的结构化请求。 |
| 当事人信息 | 当前覆盖基本身份和联系方式，但缺少官方表中的工作单位、职务、经常居住地、证件类型、法人类型、所有制性质、第三人等要素。 |
| 管辖与保全 | 当前只采集建议管辖法院；没有仲裁／法院管辖约定和诉前保全栏目。 |
| 事实要素 | 当前叙述覆盖合同签订日期、租赁期限、租金、欠租期间和金额；缺少合同名称／编号／地点、面积／产权、支付方式细分、其他费用、违约责任、解除条件、交付时间、押金、租金支付历史、请求依据等要素。 |
| 调解意愿 | 官方表含调解了解和先行调解意愿栏；当前没有。 |
| 证据清单 | 官方起诉状内只有“证据清单（可另附页）”栏目；当前另行生成独立证据清单。 |
| 送达地址确认书 | 本次官方来源的租赁部分未发现对应表格；当前独立文书没有官方对应模板。 |

**结论边界：** 当前输出可作为“出租人追索欠租”的项目自拟叙述式初稿，但不能描述为已符合官方要素式起诉状，也不能因为本比较完成就加入中央映射或视为法律审阅通过。

## 3. 分节比较

### 3.1 标题、说明与版式

| 官方文本 | 当前输出 | 差异分类 |
|---|---|---|
| 标题为“民事起诉状（房屋租赁合同纠纷）”，含案由副标题 | 标题只有“民 事 起 诉 状” | `FORMAT_DIFFERENCE` |
| 含填表说明、诚信诉讼特别提示 | 无填表说明或诚信提示 | `FORMAT_DIFFERENCE` |
| 要素式表格，含勾选项和可扩容栏目 | 叙述式段落，无勾选项 | `FORMAT_DIFFERENCE` |

这些差异主要是版式差异，不等同于法律缺陷；是否采用官方版式属于映射审查和产品范围决策。

### 3.2 当事人信息

| 官方栏目 | 当前覆盖 | 差异 |
|---|---|---|
| 原告（自然人）：姓名、性别、出生日期、民族、工作单位、职务、联系电话、住所地、经常居住地、证件号码、证件类型 | 姓名、性别、出生日期、民族、职业、证件号码、住址、电话 | 缺少工作单位／职务区分、经常居住地、证件类型 |
| 原告（法人、非法人组织）：名称、住所地、注册地／登记地、法定代表人／负责人、职务、联系电话、统一社会信用代码、单位类型、所有制性质 | 名称、统一社会信用代码、法定代表人、住所地、电话 | 缺少注册地／登记地、法定代表人职务、单位类型、所有制性质 |
| 被告（自然人／法人、非法人组织） | 与原告相同的自然人和公司字段 | 同原告的缺项 |
| 第三人（自然人／法人、非法人组织） | 无 | 当前 `PartyManager` 只支持原告和被告 |
| 委托诉讼代理人：有／无、姓名、单位、职务、联系电话、一般授权／特别授权 | 姓名、代理人类型、单位、电话 | 缺少代理权限和职务；未区分一般／特别授权 |

当前当事人块是叙述式段落，官方是表格；这不影响叙述式起诉状的成立，但无法直接对应官方表格的栏目结构。

### 3.3 诉讼请求

官方表在自由表述诉讼请求之外，另设 12 项要素。官方还按原告角色给出填写指引：出租人填写第 1、2、5、6、7 项，承租人填写第 3、8 项，第 4、9 至 12 项为共同项。

| 官方要素 | 当前输出 | 差异 |
|---|---|---|
| 1. 支付租金（到期未付租金及明细） | 第 2 项请求：欠付租金金额＋欠租期间 | 基本覆盖；官方另设“明细”栏 |
| 2. 迟延支付租金的利息（违约金）：截止日、利息／违约金、计算基数、计算标准、是否至实际清偿日、计算方式 | 第 3 项请求：固定金额“违约金（滞纳金）” | 部分覆盖；缺少计算方式、基数、标准、截止日和“至实际清偿之日止”选择 |
| 3. 交付房屋 | 无 | 缺失；承租人场景 |
| 4. 请求解除合同（是：确认合同于某日解除；否） | 仅在“请求解除”状态下提出解除请求；已解除状态只在事实中陈述解除日期 | 条件性差异；已解除状态没有“确认解除”的请求 |
| 5. 返还租赁物，并赔偿因解除合同而受到的损失 | 第 4 项请求：腾退并返还房屋；没有损失赔偿 | 部分覆盖；返还与损失赔偿未拆分 |
| 6. 支付房屋占有使用费 | 无 | 缺失 |
| 7. 支付水电费等费用 | 无 | 缺失 |
| 8. 返还押金 | 无 | 缺失；承租人场景 |
| 9. 是否主张实现债权的费用 | 只能通过“补充诉讼请求”自由填写 | 部分覆盖；没有结构化栏目和提示 |
| 10. 是否主张诉讼费用 | 固定请求“本案诉讼费由被告承担” | 覆盖；官方为可选，当前默认主张 |
| 11. 其他请求 | 支持“补充诉讼请求” | 部分覆盖；自由文本，无栏目校验 |
| 12. 标的总额 | 无 | 缺失；当前不计算或填写诉讼请求总额 |

### 3.4 约定管辖和诉前保全

| 官方栏目 | 当前输出 | 差异 |
|---|---|---|
| 有无仲裁、法院管辖约定；有则填写合同条款及内容 | 只有“建议管辖法院” | 缺失 |
| 是否已经诉前保全；是则填写保全法院、时间、案号 | 无 | 缺失 |

### 3.5 事实与理由

官方表在自由表述事实与理由之外，另设 15 项要素。

| 官方要素 | 当前输出 | 差异 |
|---|---|---|
| 1. 合同签订情况（名称、编号、签订时间、地点等） | 合同签订日期；叙述中出现“《房屋租赁合同》” | 部分覆盖；缺少合同编号和签订地点 |
| 2. 签订主体（出租人、承租人） | 原告、被告当事人信息 | 部分覆盖；未标注出租人／承租人角色 |
| 3. 租赁标的物情况（坐落位置、面积、产权情况等） | 房屋地址 | 部分覆盖；缺少面积、产权情况、出租权依据 |
| 4. 合同约定的租赁期限 | 租赁起始、到期日期 | 覆盖 |
| 5. 合同约定的租金及支付方式（月租金、总价、支付工具、一次性／分期、分期方式） | 月租金；支付方式为自由文本 | 部分覆盖；缺少总价、支付工具类型、一次性／分期和分期明细 |
| 6. 其他费用约定（物业费、水电燃气费用等；出租人／承租人负担） | 无 | 缺失 |
| 7. 合同约定的违约责任 | 无；只有“违约金／滞纳金”金额 | 缺失；缺少合同条款依据 |
| 8. 是否约定合同解除的条件及具体内容 | 无 | 缺失 |
| 9. 租赁物交付时间 | 无 | 缺失 |
| 10. 押金约定情况（有无、数额、支付日期） | 无 | 缺失 |
| 11. 租金支付情况（期间、已付租金、逾期但已付租金、明细） | 无；只有欠租金额 | 缺失 |
| 12. 逾期未付租金情况（起算日、截止日、欠付金额） | 欠租起始、截止日期和金额 | 覆盖 |
| 13. 其他需要说明的内容 | 支持“补充事实与理由”自由文本 | 部分覆盖 |
| 14. 请求依据（合同约定、法律规定） | 无；结尾只有“为维护原告合法权益” | 缺失；需要法律审阅，不能自动生成法律依据 |
| 15. 证据清单（可另附页） | 另行生成独立证据清单；起诉状正文未写“后附证据清单” | 部分覆盖；缺少起诉状内的衔接表述 |

### 3.6 对纠纷解决方式的意愿

官方表包含调解了解情况和是否考虑先行调解的选择。当前程序没有对应字段或段落。该栏目属于程序意愿，不是欠租请求成立的必要事实，但属于官方表格的结构差异。

### 3.7 尾部、附件与页码

| 官方文本 | 当前输出 | 差异 |
|---|---|---|
| “具状人（签字、盖章）：”“日期：” | “具状人：”“年 月 日” | 版式差异；当前没有“签字、盖章”提示 |
| 官方表格按页印刷页码 | 当前 Word 页脚自动页码 | 形式不同，功能相近 |
| 官方正文含证据清单栏目 | 当前另附“本状副本 N 份”和独立证据清单 | 结构差异 |

### 3.8 证据清单与送达地址确认书

- 官方租赁起诉状内只有“证据清单（可另附页）”栏目，实例写“后附证据清单”；本次 PDF 的租赁部分未发现独立的官方证据清单模板。
- 当前独立证据清单为四列表格（序号、证据名称、证明对象／目的、备注），属于项目自拟文书，不能称为官方模板。
- 本次官方来源的租赁部分未发现送达地址确认书；当前送达地址确认书同样是项目自拟文书。该陈述只限本次检查的来源。

## 4. 条件性差异

| 条件 | 官方表处理 | 当前处理 | 影响 |
|---|---|---|---|
| 原告是出租人还是承租人 | 按角色分流：出租人填 1、2、5、6、7；承租人填 3、8；4、9–12 为共同项 | 没有原告角色字段；模型和事实叙述按出租人追索欠租设计 | 当前不能可靠生成承租人请求（交付房屋、返还押金等） |
| 合同继续履行 | 仍可主张租金、违约金等 | 只主张欠租和可选违约金；不主张解除或腾退 | 基本一致，但缺少其他费用等要素 |
| 合同已经解除 | 第 4 项可勾选“确认合同于某日解除” | 事实中陈述解除日期；不提出确认解除请求 | 是否需要确认请求属于法律审阅问题 |
| 请求解除合同 | 第 4 项“请求解除合同”，第 5 项返还租赁物并赔偿损失 | 提出解除请求；未腾退时提出返还请求；不主张损失赔偿 | 请求范围较窄 |
| 房屋是否返还 | 要求明确是／否 | 三态：已腾退／未腾退／未确认；只有“未腾退”才生成返还请求 | “未确认”会抑制返还请求，属于保守处理，但可能遗漏请求 |
| 欠租金额 | 到期未付租金＋明细；另有租金支付历史 | 欠租金额＋欠租期间 | 缺少已付租金、逾期已付租金和支付明细 |
| 违约金／利息 | 计算基数、标准、截止日、是否至实际清偿日 | 固定金额 | 无法表达计算型违约金或继续计算至清偿日 |
| 解除日期 | 第 4 项要求填写解除日期 | 仅“已解除”状态要求填写；请求解除状态没有解除日期 | 请求解除的解除日期通常由裁判确定，需法律审阅 |
| 补充内容 | 可另附页、可扩容 | 补充诉讼请求和补充事实与理由自由文本 | 可部分弥补缺项，但没有结构化校验 |
